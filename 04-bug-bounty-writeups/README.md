# 🐛 Bug Bounty Write-Ups & Vulnerability Research

This section documents my hands-on participation in bug bounty programs and vulnerability disclosure platforms. It tracks my methodology, reconnaissance workflows, and structured write-ups for issues investigated or submitted (including lessons learned from duplicate reports).

## 🔍 Methodology & Approach

* **Reconnaissance & Asset Discovery:** Gathering targets, mapping subdomains, and identifying exposed endpoints.
* **Vulnerability Analysis:** Investigating web application logic flaws, examining common security misconfigurations, and testing parameters safely.
* **Disclosure & Reporting:** Practicing professional vulnerability reporting and understanding the triage lifecycle.

---

## 📂 Section Layout

* **`screenshots/`** – Contains visual proof of testing, and responses i got.
* **`write-ups/`** – Step-by-step breakdowns of findings and key security takeaways.

*Note: Dealing with duplicate submissions is a normal part of the bug bounty learning curve; this folder documents both successful verifications and the analytical process behind them.*
